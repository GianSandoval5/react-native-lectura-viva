Borrador pendiente de publicación: ¿Cuántos libros empiezas y nunca terminas? Lectura Viva convierte cada sesión de lectura en progreso visible. Diseñé una biblioteca personal con React Native y Expo, registro de páginas, minutos y notas, historial y estadísticas. El proyecto integra MobileLab como sandbox de datos persistente con SQLite y una capa de repositorios intercambiable. La experiencia se apoya en reglas sencillas que evitan registrar más páginas de las que quedan y preservan el historial cuando editas un libro. El objetivo es mostrar cómo una necesidad cotidiana se traduce en un producto móvil con límites claros y pruebas reproducibles. ¿Qué hábito te gustaría convertir en una app?
